확인일:2026-10-21. 실제 공개 배포 파일과 기존 REA 브라우저 증거만 읽었습니다. 앱 파일 변경, 로그인 이후 자료 조회, 인증 우회, 전체 DB 복제는 하지 않았습니다. 기계 판독용 상세 목록은 [JSON 보고서](gg-data-static-api-2026-10-21.json)에 있습니다.

## 확인된 구조

**공통 외부 API 하나로 모든 자료를 읽는 구조라는 증거는 없습니다. 현재 확인된 것은 Wiki/클라이언트 참조를 넣은 정적 JS 데이터와, 글클메지지 자체 서버 API의 조합입니다.**

- 도감·퀘스트·공식·스킬: 배포 JS에 실제 데이터 객체가 들어 있습니다. 출처에는 MapleClassic Wiki가 표시됩니다. 스킬 화면은 Wiki와 테스트 클라이언트 확인 자료를 근거로 설명합니다.
- 시세·고확: 공개 시세 설명은 자체 수집기가 게임 화면에서 읽은 확성기를 사용한다고 밝힙니다. 장비는 자체 거래소 매물을 옵션별로 구분합니다. 브라우저는 글클메지지의 `/api/prices`, `/api/megaphones`를 호출했습니다.
- 이미지: `/codex/...`, `/item-icons/...`, `/skill-anim/...` 같은 자체 도메인의 정적 파일과 `/api/item-icon`을 사용합니다. 로컬 파일명만으로 서버가 어떤 WZ/API에서 가져왔는지는 알 수 없습니다.

이것은 공개 클라이언트에서 확인한 구조입니다. 서버 내부의 DB 제품, 수집기 코드, 빌드 시 가져오는 다른 자료, 서버가 호출하는 외부 서비스까지 확인한 결과는 아닙니다.

## 재사용에 연결할 수 있는 경로

게임 사실·공식은 글클메지지가 출처로 표시한 **MapleClassic Wiki 원본**과 현재 클라이언트 자료를 직접 검증하는 경로가 확인됐습니다. 정적 번들에는 추가로 정리·번역한 자료가 들어 있으므로 이를 원본 데이터 전체와 같다고 취급하지 않습니다.

시세와 고확은 사이트 설명상 자체 수집 자료입니다. 별도 담당자가 같은 날08:50UTC에 새 익명 Chrome으로 `/api/prices`, 특정 아이템 상세, 실시간1행을 읽었을 때는 모두200이었습니다. 집계385아이템·자체매물 구분·실제 원문 관찰시각까지 확인했습니다. 자세한 결과는 [현재 시세 API 실응답 보고서](gg-market-source-trace-2026-10-21.ko.md)에 있습니다. 위08:49UTC의 다른 세 경로 CLI403과 이번 가격 경로 Chrome200은 서로 다른 조건의 관찰이므로 원인은 미확인입니다. 이전403 기록만으로 지금 모든 API가 차단됐다고 결론내리지 않습니다.

이번 범위에서 개발자용 공개 API 문서·재사용 계약은 확인하지 못했습니다. 주소를 알아냈다는 사실과 안정적으로 연동하거나 재사용할 수 있다는 판단을 구분합니다. 인증 뒤의 부엉이 결과나 그 API는 확인하지 않았습니다.

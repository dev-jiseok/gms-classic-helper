# 0.6.1 돈퀘 공용 가치 정렬·사용 설명서 검증

검증일:2026-10-21. 사용자가 요청한 기준은 **직업별 효율이 아닌 공용 보상 가치 우선**입니다.

## 변경 이유와 결과

기존 돈퀘 정렬은 금액 비교 전에 수행 가능·전직 필수·종료 임박·선행 준비 점수를 비교했습니다. 비용 자료가 부족해 순가치를 구하지 못하는 의뢰도 많아, 사용자가 기대한 보상 금액순으로 보이지 않았습니다.

- 기본 정렬은 해당 의뢰 자체의 확정 메소와 평가 가능한 확정 보상 아이템을 합한 공용 보상 가치순입니다.
- 직업·실제 전직·레벨 등은 수행 가능 조건에 사용합니다. 직업의 사냥 성능·보유 재료·미완료 선행 보상은 기본 보상 금액에 더하지 않습니다.
- 수행 가능한 의뢰가 먼저이며, 미확인/부족 조건을 포함해 보는 경우에도 두 그룹 안에서 각각 금액을 비교합니다.
- 비용 차감 순가치와 시간당 순가치는 선택 정렬입니다. 선행 포함 보상·비용·시간은 기본 공용 가치와 별도로 표시합니다.
- 미확인 보상은 확인된 부분만 표시하며, 가격이 전혀 없으면 확인 필요로 남깁니다. 미확인 비용을0으로 바꿔 순이익을 만들어내지 않습니다.
- 완료·보유 재료 변경은 활동 잠금이 없을 때 재계산합니다. 이전 엔진의 저장 순위는 갱신합니다.

[42개 기능 사용 설명서](../web/docs/README.md)에 프로필 설정·돈퀘 예시·각 화면 입력 순서·보상과 순가치의 차이·저장 및 공유·문제 해결을 정리했습니다. 42개 기능 앵커·경로와 README 상대 링크를 확인했습니다.

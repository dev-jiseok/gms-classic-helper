# 글클메지지 데이터 원천과 API 확인 결과

확인:2026-10-21 17:47–17:56 KST. 공개 배포 파일·REA 증거·익명 API 응답을 읽었습니다. 앱이나 배포는 변경하지 않았습니다.

**정적 도감은 Wiki 기반 자료를 정리한 배포 번들, 시세는 자체 수집 자료를 주는 별도 API입니다. 데이터 확보와 같은 기능 구현을 위해 원본 서버 소스가 반드시 필요한 것은 아닙니다.** 원본 계정·게시물·서버 저장소 전체의 이전과는 작업 범위가 다릅니다.

공통 외부 가격 서비스가 있는 것으로 확인한 것은 아닙니다. GG 화면 설명과 코드가 밝히는 흐름은 `자체 확성기 화면 수집·자체 거래소 → 자체 시세 응답 → 브라우저`입니다. 서버 내부 DB 제품·숨은 외부 호출은 공개 클라이언트에서 미확인입니다. API 존재·HTTP200 확인과 외부 개발자용 연동 계약은 별도입니다.

## 정적 데이터는 추측 없이 확인됨

공개 JS3개를 HTTP200으로 확보해 REA로 분석했고, AST 문자열 리터럴을 정적으로 변환해 표 구조와 행 수를 확인했습니다. 번들 부트스트랩·대상 코드를 실행하지 않았고 복원한 전체 DB나 고유 번역문을 앱에 복사하지 않았습니다.

주요 관계 번들에는 실제로 다음 자료가 있습니다.

별도의 기본 검색·공략용 부분 도감과 한국어 사전도 존재합니다. 기본 도감의 `updated`는2026-10-11이며 이것을 서버 보정과 합친 최신 자료의 시각으로 해석하지 않습니다. 다른 버전 참고 드롭표도 있어 현재 서버 확정 확률과 분리해야 합니다.

원천 Cargo의 이번 실제 예: [몬스터2 조회](https://mapleclassic.wiki/api.php?action=cargoquery&tables=monsters&fields=id,name_en,level,hp,exp&where=id%3D2&limit=5&format=json)는200, `cargoquery[].title` 안에 Snail·Lv1·HP45·EXP2를 반환했습니다. 우리 수집기의 테이블명과 GG support 테이블이 대응하고 포털536·상점품목555·제작348·표본드롭158행도 일치합니다. 주요 정적 자료를 같은 원천에서 직접 구축할 수 있다는 구체적인 근거입니다. 자료 이용 시 해당 Wiki의 출처·라이선스·변경 이력을 유지합니다.

## 우리 앱에 적용할 구체적인 차이

- 기존 우리 도감은 이미 IO와 Wiki를 조합한 로컬 JSON 스냅샷입니다. 목록 수를 늘리는 것보다 GG에 있는 독립적인 `quest_steps` 진행 단계·NPC 동선 설명을 수집·연결하는 갭이 남습니다.
- GG 고유 번역·편집 공략은 공개 Wiki 사실·클라이언트 자료와 분리합니다. 이름이 같은 자료를 통째로 같은 데이터로 간주하지 않습니다.
- 가격을 추가 연동한다면 기존 Cozy 가격과 GG 확성기 호가를 출처별로 보존해야 합니다. 이번GG385행 중321행은 우리 숫자ID와 일치하고64행은 미일치하므로 별칭/사용자정의 ID를 검증할 adapter가 필요합니다. 같은 공급원 또는 같은 체결 표본이라고 합치지 않습니다.
- 몬스터 상세404가 실제 이미지 부재를 뜻하지 않는 사례도 찾았습니다. 달팽이2의 정적 프레임과 주황버섯9의 GIF/WZ 원프레임은 존재하므로 실제 포즈를 검증하는 이미지 대체 경로로 복구할 수 있습니다. 이번 조사에서는 앱 변경을 하지 않았습니다.
- 정적 원천은 버전·해시·변경 페이지를 보고 저장 갱신하고, 가격은 별도 짧은 캐시·원 관찰시각을 유지합니다. 가격 확인과 추천 재계산 주기를 분리하는 기존 구조가 적합합니다.

## 검증 범위

과거 일반 CLI/API 요청에는403이 있었고 이번 익명 Chrome 가격3경로는200이었습니다. 서로 다른 경로·클라이언트·시각이므로 원인을 확정하지 않습니다. 브라우저 폴링 주기는 서버의 새 관찰 생성 주기가 아닙니다. 시세 본문20초·홈30초·가격 글10초라는 코드의 조회 간격과, 개별 아이템 관찰이 오래됐을 수 있다는 점을 함께 보존합니다.

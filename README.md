# 메이플 컴패스 · GMS Classic Helper

GMS Classic World의 **도감·공략·시세·캐릭터 계획을 연결하는 웹 앱**입니다. 내 캐릭터의 직업·레벨·장비·예산과 실제 사냥 기록을 바탕으로 다음 퀘스트, 사냥터, 장비 교체를 비교합니다.

글클메지지의 전체 기능과 사용 흐름을 기본으로 재현하고, 시세에 따른 사냥·퀘스트·장비 최적화와 친구들이 함께 쓰기 편한 기능을 추가하는 것이 목표입니다.

**현재 버전 `0.5.0` · 구현/검증 기준 `2026-10-21` · 6개 메뉴 / 42개 진입 화면**

[배포 앱](https://maple-compass-gms.ethan-lee394436.chatgpt.site) · [상세 기능·제약](web/docs/feature-coverage.ko.md) · [앱 개발 안내](web/README.md) · [사이트/API 분석](research/gg-api-findings-2026-10-21.ko.md)

> 배포 앱은 현재 소유자만 접근할 수 있습니다. 글클메지지의 실시간 시세 연동과 로그인 이후 기능까지 완전히 이관된 상태는 아닙니다.

## 추가 최적화 기능의 동작

- **사냥터:** 직업·레벨·스탯이 맞는 실측 기록을 우선하고, 경험치와 현재 시세로 재평가한 수익을 함께 비교합니다. PQ·전직시험 몬스터는 일반 사냥 후보에서 제외합니다.
- **퀘스트:** 돈퀘와 경험치 목표를 나누고, 공통 선행·보유 재료·실제 소비량·구매비를 반영합니다. 문장에 없는 목적지·소요 시간을 임의로 만들지 않습니다.
- **장비:** 확인된 매물의 실제 옵션과 예산·착용 조건을 만족하는 조합을 탐색합니다. 같은 옵션끼리 가격을 비교하며 전체 서버 최저가로 표현하지 않습니다.
- **진행 유지:** 시세 조회와 추천 계산의 주기를 분리합니다. 사냥·퀘스트를 진행 중이면 가격 변동만으로 계획을 계속 바꾸지 않습니다.

## 로컬 실행

앱은 **Node.js22.13 이상**이 필요합니다. 저장소 루트에서 실행합니다.

```sh
npm --prefix web ci
npm run dev -- --hostname 127.0.0.1 --port 5187
```

브라우저에서 `http://127.0.0.1:5187`을 엽니다. 외부 시세·이미지·랭킹을 확인하려면 네트워크 접근이 필요합니다. 앱 실행에 REA·Ghidra 설치는 필요하지 않습니다.

```sh
npm run check   # TypeScript 검사
npm test        # 앱 자동 테스트
npm run build   # 배포용 빌드
```

D1·로컬 로그인·빌드된 Worker 실행은 [앱 개발 안내](web/README.md)에 있습니다. 리버스 엔지니어링 명령과 Chrome/Ghidra 설정은 [별도 분석 환경 문서](research/README.md)에 있습니다.

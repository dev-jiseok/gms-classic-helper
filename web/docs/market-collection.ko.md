# 공개 시세 이력 수집

이 사이트의 소유자 전용 비공개 접근 범위를 유지한 채 공개 Cozy 관찰만 서버에 보관합니다. 개인 프로필·관심 조건·쪽지·연결 계정은 읽거나 변경하지 않습니다. 브라우저의 시세 확인은 기본 60초, 추천 스냅샷은 기본 1시간이며 서로 별개입니다.

## 무인 실행 경로

1. 연결된 Site의 `get_site`에서 현재 소유자 전용 접근과 지원되는 서비스 접근을 확인합니다. 공개로 바꾸지 않습니다.
2. 해당 Site의 `POST /api/market/collect`를 호출합니다. 서비스 접근은 Sites가 검증하며 방문자 계정으로 가장하지 않습니다.
3. `GET /api/market/collect`로 `fetchedAt`, `sourceUpdatedAt`, `quoteCount`, `history.rows`, `history.newestAt`를 읽어 보관을 확인합니다.
4. 공급원이 지연되면 마지막 정상 자료와 원래 관찰 시각을 유지합니다. 429·실패 대기를 건너뛰지 않습니다. 저장소 실패는 503으로 드러납니다.

지원되는 접근 수단은 Sites의 서비스 접근 설명을 따릅니다. 자격증명은 실행할 때 취득해 해당 Site 요청에만 사용하며 소스·프롬프트·로그에 남기지 않습니다. Sites 서비스 토큰은 개인 상태 API의 로그인 권한을 제공하지 않습니다.

## 보관 범위와 검증

- D1의 공급원별 60초 lease로 중복 조회를 줄이고 같은 관찰은 중복 저장하지 않습니다.
- 관찰 시각 기준 30일을 보관합니다. 공급원 차트와 보관 이력은 아이템별 최대 2,000개 실제 점으로 합칩니다. 설치 이전 30일 전체 이력을 만들어내지 않습니다.
- 가격 조회 시각과 실제 상점 관찰 시각을 구분합니다. 매진 행의 판매 추정은 실제 거래 원장이 아닙니다.
- 브라우저가 닫힌 동안 개인 관심 조건을 검사하거나 푸시 알림을 보내는 기능은 포함하지 않습니다.
- 로컬 SQLite 테스트에서 로그인 없는 공유 수집·저장·재조회·중복 방지와 실제 API의 D1 보관을 확인했습니다. 호스팅 무인 접근 검증 결과는 배포 후 별도로 남깁니다.

상태는 시세 노트의 **연결·갱신 → 서버에 보관된 공개 시세**에서 확인합니다. 일정은 Sites에 연결된 예약 작업에서 관리하며, 예약 실행은 자료만 갱신하고 재배포하지 않습니다.

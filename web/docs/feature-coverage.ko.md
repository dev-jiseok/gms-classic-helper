# 기능 대조표와 검증 범위

2026-10-21. 기준은 **글클메지지에서 관찰한 전체 기능 + 사용자가 요청한 전 직업·효율 추천**입니다. 메뉴의 존재와 데이터 공급·실사용 검증을 구분합니다. 원본의 로그인 이후 기능 전체를 검증한 것은 아니므로, 이 표를 원본 내부 구현의 완전한 복제 증명으로 해석하지 않습니다.

0.4.0 화면은 가로6개 분류·이미지 홈·게임 패널·시세 목록/상세2단·실제 도감/추천 이미지·모바일 하단탭으로 재구성했습니다. [화면·이미지 재현 설명](visual-reconstruction.ko.md)에 근거와 제한을 기록했습니다.

0.5.0은 공개 원천17개 테이블·278개 열을 끝까지 수집하고, 아이템 도감·몬스터 도감·성장 추천 퀘스트를 원본 메뉴처럼 분리했습니다. 퀘스트 진행 단계837개, 상점 본체30개, 판매 품목555개를 연결하고 설정에서 모든 원천표를 검색할 수 있습니다. 현재 클라이언트와 이름·ID 연결을 확인하지 못한 항목은 위키 참조로 보관하며 실행 추천에서 제외합니다. 전체 수집 완료는 글클메지지의 비공개 DB·회원 데이터·실시간 시세까지 이관했다는 뜻이 아닙니다.

## 검증 근거

- TypeScript 검사와 기능 계산/조건 테스트를 실행합니다.
- 42개 진입 화면을 실제 Chrome에서 렌더링하고 전체 모바일 메뉴 이동·가로 넘침·실제 진행 단계·공개 원천표 검색·이미지 복구를 확인했습니다.
- 랭킹·공식 소식·도감 상세·포털 경로·코디 PNG/GIF를 실제 외부 API 응답으로 확인했습니다.
- 배포용 Worker의 로컬 실행에서 서로 다른 임시 계정 4개로 공유/권한/동시성 32개 항목을 확인했습니다.
- 제작 비용·저장, 퀘스트 완료·검색, SP, 사냥 기록·활동 유지·장비 조합, 시세 관심 알림·OCR 후보 확인을 실제 입력으로 검증합니다.
- 390px 모바일 화면과 실제 Tesseract 테스트 이미지 인식을 확인했습니다. 이것을 실제 게임 화면 검증으로 표현하지 않습니다.

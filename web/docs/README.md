## 처음 사용할 때

### 1. 현재 캐릭터부터 맞추기

오른쪽 위 캐릭터 이름을 누르면 **모험가 프로필**이 열립니다. 이름 옆 **캐릭터 선택**으로 다른 캐릭터를 고릅니다. 새 캐릭터는 **게임 시작 → 내 공간 · 백업 → + 캐릭터 추가**에서 만듭니다.

| 입력 | 쓰이는 곳 | 입력 방법 |
| --- | --- | --- |
| 현재 레벨 | 퀘스트 조건, 사냥 후보, 명중, 장비 조건, 경험치 | 게임의 실제 레벨. 스킬 계획의 목표 레벨과 별개 |
| 직업 목표 | 공략·스킬·장비 방향 | 처음부터 파이터·어쌔신·헌터 등 목표 선택 가능 |
| 실제 현재 전직 | 직업 제한 퀘스트·장비 조건 | 아직 전직 전이면 초보자,1차를 했다면 전사/도적/궁수 등,2차 후 해당 직업. 빈 선택은 레벨·목표로 예상하므로 실제 상태가 다르면 직접 지정 |
| 보유 메소 | 비용이 드는 퀘스트, 장비 예산 | 지금 쓸 수 있는 실제 금액 |
| STR·DEX·INT·LUK | 착용 가능 여부, 전투 계산, 실측 비교 | 현재 착용 장비가 반영된 게임 수치를 확인해서 입력 |
| 현재 무기 공격력 / 현재 총 마력 | 전투 계산·사냥 조건 비교 | 무기 공격력과 총 마력은 서로 다른 입력이며 직업에 맞게 입력 |
| 현재 명중 스탯 | 사냥 실측 조건 비교 | 알고 있는 현재 수치. 전투 계산 화면의 총 명중 직접 입력도 별도로 확인 |
| 인기도 | 인기도 제한 퀘스트·장비 | 모르면 빈칸. 확인된0은0, 음수도 그대로 입력 |
| 현재 위치 | 캐릭터 메모 | 지도 경로는 해당 도구의 출발 맵을 별도로 선택해야 함 |
| 성장 목표 | 성장 메모·기록 비교 | 경험치/메소/균형. 돈퀘 정렬은 돈퀘 화면의 선택이 별도로 결정 |

**프로필 저장**을 누릅니다. 기본 세 캐릭터도 시작 예시값이므로 실제 게임 수치로 수정하세요. 캐릭터를 추가해도 게임 계정에 캐릭터가 생성되지는 않습니다.

퀘스트 완료, 보유 재료, 사냥, 스킬, 장비 계획은 현재 선택한 캐릭터를 기준으로 기록합니다. 공통 시세와 일부 공간 설정은 계정·모험 공간 단위입니다. 다른 사람의 캐릭터를 쓰기 전 오른쪽 위 이름부터 확인하세요.

### 2. 추천을 정확하게 만드는 순서

1. 실제 레벨·현재 전직·보유 메소를 저장합니다.
2. 이미 끝낸 퀘스트를 **퀘스트** 도감에서 완료 처리합니다. 선행을 끝냈다면 선행도 기록합니다.
3. 퀘스트 묶음 계획의 **준비 재료**에서 가진 재료 수량을 입력합니다.
4. **시세 노트**에서 현재 관찰 가격·옵션·시각을 확인합니다. 필요한 가격이 없으면 직접 확인한 가격을 기록합니다.
5. 돈퀘·사냥·장비 화면에서 필요한 조건을 입력하고 **추천 새로 계산**을 누릅니다.
6. **확인 필요**, 미평가 보상, 오래된 가격이 남아 있으면 그 결과를 확정 수익으로 읽지 않습니다.

레벨·현재 전직·완료·재료 보유량은 활동 잠금이 없을 때 퀘스트 추천에 자동 반영됩니다. 시세 조회는 보통60초, 추천은 기본1시간 단위입니다. 최신 가격·보상·시간을 직접 보완했다면 새로 계산하세요. 활동을 시작하면30/45/60분 동안 해당 종류의 추천 순서가 고정되므로 바꾸려면 **활동 마침 · 잠금 해제**를 누릅니다. 사냥 측정도 진행 중이면 먼저 사냥 기록에서 정상 종료/취소하세요.

### 3. 돈퀘스트를 실제로 찾는 예

예를 들어 현재25레벨 전사이고 파이터를 목표로 한다면 프로필을 **현재 레벨25 / 직업 목표 파이터 / 실제 현재 전직 전사 / 실제 보유 메소**로 저장합니다. 현재 레벨을 목표인30으로 올려 놓으면 아직 할 수 없는 퀘스트가 수행 후보에 들어갈 수 있습니다.

**육성 · 퀘스트 공략 → 돈 버는 퀘스트**를 열고 **돈퀘스트 정렬 → 공용 보상 가치 높은 순 · 기본**을 고릅니다. 이 정렬은25레벨에 가까운 퀘스트만 고르는 방식이 아닙니다. 레벨·전직 등 조건을 통과한 미완료 의뢰 중 **현재 확인된 보상 가치가 큰 순서**입니다. 저레벨 의뢰도 안 했다면 올라올 수 있습니다.

| 선택 | 비교하는 값 | 필요한 자료 |
| --- | --- | --- |
| 공용 보상 가치 높은 순 · 기본 | 해당 의뢰 자체의 확정 메소 + 가격을 확인한 확정 보상 아이템 가치. 직업 성능·보유 재료·미완료 선행 보상은 반영하지 않음. 전체 보상이 불명확하면 확인된 부분만 사용 | 보상·수량·가격. 비용이나 시간이 미확인이어도 이 값은 비교 가능 |
| 비용 차감 순가치 높은 순 | 전체 보상 가치 − 실제 소모 재료의 가치 − 진행 메소 비용 | 전체 보상·소모·비용·조건 확인 필요 |
| 시간당 순가치 높은 순 | 순가치 ÷ 선행·이동 포함 시간 ×60 | 순가치와 각 의뢰의 소요 시간 확인 필요 |

예를 들어 A가 보상10,000·비용9,000, B가 보상9,000·비용100이면 기본 보상순은A가 먼저지만 순가치순은B가 먼저입니다. 비용을 모르면A의 순이익이10,000이라고 계산하지 않습니다. **보상 가치가 높다**와 **돈이 많이 남는다**를 구분하세요.

카드의 **공용 보상 가치 · 이 의뢰만**이 기본 정렬 금액입니다. 같은 의뢰는 같은 가격 자료라면 파이터·표도·궁수 등 직업, 보유 재료, 선행 완료 상태에 관계없이 같은 금액을 사용합니다. 직업·레벨·진행 조건은 수행 가능한 후보를 거르는 데 쓰입니다. 선행 포함 보상 가치·순가치·재료 준비 구매비·시간은 별도 참고값입니다. **확인된 일부 보상 · 미평가 항목 있음**은 전체 보상 가치가 아니며, 가격 없는 주문서나 랜덤 보상이 더 있을 수 있습니다. 기본 순위는 확인된 부분으로 비교한 결과이지 전체 서버의 확정 돈퀘 순위가 아닙니다.

## 게임 시작과 기록 관리

<a id="today"></a>
### 오늘의 모험 · `/`

**먼저:** 현재 캐릭터를 선택하고 레벨·현재 전직을 저장합니다.

- 오늘의 상태·주요 기능·공식 소식·바로가기를 확인합니다.
- 캐릭터 이름이나 선택 메뉴로 편집·전환합니다. 퀘스트·도감·사냥·시세 카드를 눌러 작업을 이어갑니다.
- 첫 화면의 안내를 읽은 것만으로 실제 전직·퀘스트가 완료되지는 않습니다. 완료 기록은 해당 도구에서 직접 남깁니다.

<a id="start"></a>
### 게임 시작 가이드 · `/start`

계정·런처·설치·접속·캐릭터 생성·첫 전직 준비의 체크리스트입니다. 실제로 끝낸 항목만 체크하며 기록은 캐릭터별로 저장합니다. 공식 원문 링크에서 현재 설치·지역 조건을 확인하세요. 도우미가 게임 설치나 전직을 대신 수행하지 않습니다.

<a id="errors"></a>
### 실행 오류 해결 · `/errors`

점검 여부, 런처 업데이트, 파일 검사, 언어·화면 설정 등 실제로 점검한 항목을 체크합니다. 계속 실패하면 오류 코드·발생 시각·상황을 게임 공식 지원에 전달할 자료로 남기세요. 체크리스트 완료는 게임 오류가 해결됐다는 자동 진단이 아닙니다.

<a id="events"></a>
### 이벤트 · 일정 · `/events`

공식 출시 이벤트의 기간·참여 레벨·계정/캐릭터 단위·보상을 읽고, 직접 확인한 달성 시각이나 체크를 기록합니다. 거래 제한 해제처럼 시각 입력이 필요한 항목은 실제 게임의 달성 시각을 입력하세요. 개인 일정은 제목·마감·공식 링크로 추가합니다. 개인 체크가 게임 서버의 수령 이력과 자동 동기화되지는 않습니다. 시간은 화면에 표시된 시간대와 원문을 함께 확인합니다.

<a id="ranking"></a>
### 캐릭터 랭킹 · `/ranking`

이름 검색 후 직업 계열·세부 직업·정렬·페이지를 선택합니다. 캐릭터를 눌러 상세·최근 관찰 시각을 보고 관심 캐릭터에 추가할 수 있습니다. **프로필에 반영**을 쓰면 현재 선택 캐릭터의 이름·레벨·알아낸 직업을 바꾸므로 본인 캐릭터인지 먼저 확인하세요. 현재 전직·스탯·장비는 따로 대조합니다. 공개 공급원의 관찰 순위이며 첫1,000개 결과 범위 제한이 있습니다.

<a id="settings"></a>
### 내 공간 · 백업 · `/settings`

- **+ 캐릭터 추가**: 닉네임·목표 직업을 선택합니다. 새 프로필은1레벨·초보자 현재 전직에서 시작합니다.
- **프로필 수정**: 실제 레벨·전직·수치를 입력합니다. 스킬 목표 레벨은 스킬 화면에서 별도 설정합니다.
- **전체 백업 다운로드**: 캐릭터·완료·재료·스킬·사냥 등 계정 상태를JSON으로 내려받습니다.
- **백업 복원**: 해당 앱에서 받은2MB 이하JSON을 선택합니다. 현재 기록을 바꿀 수 있으므로 복원 전 현재 상태도 백업하세요.
- 저장 상태가 **계정에 저장됨**인지 확인합니다. 로그인되지 않으면 브라우저 저장에 의존하므로 기기 변경·브라우저 데이터 삭제 전에 백업합니다.
- 다른 기기와 충돌하면 **내 기록/계정 기록**의 내용을 확인해 보존할 쪽을 선택합니다. 단순 새로고침으로 한쪽 기록을 무시하지 마세요.
- **도감 데이터 · 출처**에서17개 원천표의 범위·열·행 수를 보고 원천 자료를 검색할 수 있습니다. 원천표 존재는 해당 콘텐츠가 현재 게임에서 개방됐다는 뜻이 아닙니다.

## 육성 · 퀘스트 · 추천

<a id="guides"></a>
### 육성 공략 · `/guides`

**먼저:** 직업 목표·실제 레벨을 맞춥니다. **내 직업 공략/전체 공략**을 선택해 카드를 엽니다. 상세의 적용 상황·공식/커뮤니티 근거·대조일·상충하는 설명을 먼저 읽고 단계별 안내를 따릅니다. **관련 퀘스트 보기**, **스킬 계획하기**로 이동할 수 있습니다. 공략 원문 대조와 실게임 효율 실측은 별개입니다.3차 이후·미래 지역을 현재 성장 경로로 간주하지 않습니다.

<a id="money"></a>
### 돈 버는 퀘스트 · `/moneyQuests`

**필수 설정:** 레벨·현재 전직. 비용 있는 의뢰는 보유 메소, 인기도/시민권/제작 조건이 있으면 해당 기록도 필요합니다. 완료한 의뢰는 도감에서 체크하세요. 보유 재료와 가격을 넣으면 준비 비용을 더 정확히 계산합니다.

1. **돈퀘스트 정렬**을 고릅니다. 기본은 공용 보상 가치순이며, 순가치·시간당 순가치로 바꿀 수 있습니다. 레벨이 가깝다는 이유로 보상 가치가 낮은 의뢰가 먼저 오지 않습니다.
2. 카드에서 미완료 선행·보상·준비 구매비·미확인 항목을 확인합니다. 수행 가능 의뢰가 먼저이며, 부족한 조건의 의뢰는 **조건이 부족하거나 확인되지 않은 계획도 보기**로 확인합니다.
3. **게임에서 확인한 보상·소모 비용 반영**을 펼쳐 실제로 확인한 확정 메소·진행 비용을 입력합니다. 모르면 빈칸, 비용이 없음을 확인했으면0입니다. 조건·전체 보상·실제 소모 확인 체크는 게임에서 확인했을 때만 사용합니다. 조건 확인의 유효 시간은1시간입니다.
4. 시간당 비교를 원하면 **이 퀘스트 이동 포함 예상 시간 (분)**을 넣습니다. 미완료 선행의 시간도 필요합니다. **추천 새로 계산**으로 반영합니다.
5. **묶음 계획에 담기**로 선택한 뒤 상단에서 준비 재료·진행·NPC 동선을 봅니다. 최대50개 의뢰를 함께 계획합니다.
6. **이 계획 시작**은 활동 잠금입니다. 실제 퀘스트 완료 버튼이 아닙니다. 끝나면 잠금을 해제하고 완료를 기록합니다.

기본 공용 보상 가치는 해당 의뢰만 평가합니다. 별도 표시하는 선행 포함 보상·순가치·시간은 각자의 미완료 선행을 포함하므로 여러 카드의 수익을 그대로 더하면 공통 선행이 중복될 수 있습니다. 묶음 계획은 공통 선행을 한 번만 계산합니다. 기본 추천 저장 범위는 상위60개이며 전체358개 도감과 다릅니다.

<a id="expQuests"></a>
### 성장 추천 퀘스트 · `/expQuests`

레벨·현재 전직·완료·선행·추가 조건을 확인한 뒤 경험치 중심으로 비교합니다. 돈퀘와 같은 묶음 계획·조건 보완 도구를 사용합니다. 경험치와 이동 포함 시간이 모두 있으면 시간당EXP도 표시됩니다. 금액 우선 정렬을 원하면 **퀘스트 추천 기준 → 돈퀘스트**로 바꿉니다. 경험치 보상만 높아도 긴 선행이나 왕복 때문에 실제 효율은 달라질 수 있습니다.

### 퀘스트 묶음 계획 · 돈퀘/성장 추천 화면 상단

**의뢰 찾기 → 준비 재료 → 진행·체크 → NPC 동선** 순으로 사용합니다.

- **의뢰 찾기**: 이름·ID·지역 검색 후 **계획에 담기**. 현재 조건 필터는 후보 검색용이며 미확인 스크립트 조건까지 충족했다고 보증하지 않습니다.
- **준비 재료**: 재료별 **계획 보유 수량**을 입력합니다. 미입력은 미등록이며 준비 계산에서는0개로 가정할 수 있습니다. 확인 체크는 실제 재고를 대조한 뒤 선택합니다. 보유만 필요한 재료와 소모되는 재료를 구분합니다.
- **진행·체크**: 선행 순서·현재 조건·원문 진행 단계·수락/보고NPC를 확인하고 실제로 한 단계만 체크합니다. NPC·아이템·맵을 누르면 도감으로 이어집니다.
- **NPC 동선**: **퀘스트 계획 출발 맵**을 선택합니다. NPC의 위치가 여러 곳이면 방문 맵도 고릅니다. 이동 시간·비용은 직접 확인한 값을 입력합니다.

길은 확인된 방향성 포털 수를 기준으로 참고합니다. 맵 안 보행·대기·혼잡·미확인 입장 조건까지 포함한 전역 최단 시간은 아닙니다. 같은 몬스터 목표의 겹침도 서버에서 동시 인정되는지 확인해야 합니다.

<a id="training"></a>
### 사냥터 추천 · `/training`

**먼저:** 프로필의 레벨·현재 장비 스탯을 맞추고 **사냥 기록**에서 측정합니다. 최근 기록 중 현재 캐릭터·직업·레벨·전투 스탯 등 조건이 비교 가능한 기록이 우선입니다.

1. 경험치/메소 비중과 비교할 측정 조건 메모를 정합니다.
2. 실측 결과의 측정 시간·횟수·EXP/h·기록 당시 수익·현재 시세 추정을 구분해서 읽습니다.
3. 이론 후보를 보려면 맵·대상 몬스터를 고르고 평균 피해·명중률·공격 주기·가동률·처치 상한·비용을 실제 측정한 값으로 보정합니다.
4. 장비·스킬·버프·파티 조건을 바꿨다면 새 조건을 기록합니다. 다른 조건/미확인 기록을 억지로 같은 조건으로 확인하지 않습니다.
5. 후보를 시작하면 사냥 기록으로 이동합니다. 실제 측정 시작·종료는 사냥 기록에서 합니다.

EXP/HP만으로 실제 사냥터가 최고라고 판단하지 않습니다. 전체 드롭 확률과 판매 가격·젠·경쟁이 미확인이면 시간당 순수익도 확정되지 않습니다. 희귀 드롭1회에 크게 의존하는 기록은 표본을 더 쌓아 비교하세요.

<a id="skills"></a>
### 스킬 · SP 배분 · `/skills`

**먼저:** 현재 캐릭터와 목표 직업을 선택합니다. 이 화면의 직업 변경은 프로필의 목표 직업을 바꾸므로 실제 현재 전직과 구분하세요.

1. **사용할 무기**, **목표 계획 레벨**을 입력합니다. 실제 레벨을30으로 두고40레벨 계획을 만들 수 있습니다.
2. **레벨별 SP 초안 미리보기**는 내 우선순위에 따른 자동 계획입니다. **투자 우선순위 직접 정하기**에서 순서를 바꿉니다.
3. **출처 공략 SP 미리보기**는 전사·도적(표창)·궁수1차와 파이터·어쌔신·헌터2차의 커뮤니티 배분 예시입니다. 지원하지 않는 직업/무기에는 활성화되지 않습니다. 원문과 가정을 읽으세요.
4. 미리보기의 단계별 투자·총량·미배분을 확인하고 **이 계획 적용**을 눌러 저장합니다. 미리보기만으로 현재 배분이 바뀌지는 않습니다.
5. **SP 총량을 게임에 맞추기**에서 실제 총량을 보정할 수 있습니다. 차수 규칙은 출처가 상충해 기본은 차수별 분리입니다. 하위 사용 옵션은 게임에서 확인한 경우에만 선택합니다.
6. 개별 스킬의 숫자/+/−로 조정합니다. 최대치·선행·SP를 넘기면 오류를 표시합니다. **초기화 미리보기**도 적용해야 실제로 비워집니다.
7. **현재 계획 링크 복사**로 공유합니다. 받은 사람은 미리보고 적용합니다. 실제 캐릭터 레벨은 공유 계획을 적용해도 바뀌지 않습니다.

직업을 바꾸면 이전 직업의 무기·SP·계획 레벨·규칙은 따로 보관해 돌아왔을 때 복원합니다. 출처 예시도 실게임 전체 최적성을 보증하지 않으며70레벨 이후를 임의로 채우지 않습니다.

<a id="gear"></a>
### 장비 교체 추천 · `/gear`

**필수 설정:** 실제 레벨·현재 전직·현재 총 스탯·쓸 수 있는 예산. 정확한 가격·옵션·착용 조건을 확인한 후보가 있어야 비교합니다.

1. **쓸 수 있는 메소**, 최소 총 명중, 공격력/마력/주스탯 비교 가중치를 정합니다. 마법사는 물리 공격력과 마력을 혼동하지 않습니다.
2. **시세 확인된 장비 후보 한 번에 가져오기**에서 후보·호가·누락 조건을 검토하거나, **장비 매물 가져오기**로 한 개를 불러옵니다.
3. 직접 넣을 때는 이름·부위·단가·실제 옵션·필요 레벨/스탯/직업을 모두 확인합니다. 빈 값은 확인된0과 다릅니다. 양손 무기도 표시합니다.
4. **가격과 모든 착용 조건을 확인했어요 → 비교 후보 추가**. 현재 쓰는 후보는 **현재 장비**로 지정하고 유지할 부위를 잠급니다. 현재 장비의 구매비는0으로 처리합니다.
5. **추천 새로 계산**. 예산 안의 높은 비교 점수를 찾습니다. **목표 점수**를 입력하면 그 점수를 만족하는 가장 낮은 비용의 조합을 찾습니다.
6. 실제 평균 피해·목표HP·공격/스탯1당 피해 증가를 측정한 경우에만 처치 타수 개선 보정을 입력합니다.

공격력 점수는 실제DPS와 같은 단위가 아닙니다. 옵션이 다른 장비·묶음 구매비·오래된 매물을 섞지 않습니다. 최적해는 등록된 후보와 탐색 범위 안의 결과이며 전 서버 최저가가 아닙니다.

<a id="buildnotes"></a>
### 캐릭터 빌드 노트 · `/buildnotes`

현재 캐릭터의 스탯·장비 목표·추후 육성 방향을 메모합니다. 자동 저장되는 입력란에 기록하고 스킬/장비 도구로 이동할 수 있습니다. 메모에 쓴 장비나 “보우마스터 목표”가 자동으로 착용 후보나 현재 전직이 되지는 않습니다. 구조화된 스탯·SP·후보는 각각의 도구에 입력하세요.

<a id="citizenship"></a>
### 시민권 루트 · `/citizenship`

헤네시스/커닝시티를 선택하고 실제 주민 등록 여부·게임에서 확인한 등급·기여도를 입력합니다. 일일 의뢰·주간 기부를 선택해 재료·보상·선행을 열고 확인합니다. 두 마을의 기록은 분리하며 캐릭터별로 보관합니다. 상점 할인에는 마을·등급·수량 조건이 있으므로 등록 체크만으로 모든 할인 상품을 살 수 있다고 보지 않습니다. 게임 등급 문턱이나 실제 일일 초기화를 자동 추정하지 않습니다.

<a id="pq"></a>
### 파티퀘스트 공략 · `/pq`

프로필 레벨과 입장 조건을 먼저 읽습니다. 화면의 공식 공지 범위와 게임 입장 창을 대조하세요. **새 판 시작 · 30분**으로 기록 타이머를 시작하고 실제 통과 단계를 체크합니다.1단계 질문에 맞는 쿠폰 수량을 확인한 후,2/3/4단계에서 시도한 조합을 눌러 실패 조합을 제외합니다. 새 판에서는 이전 실패 기록을 초기화합니다. 아래 보스 도감에서 몬스터·출현 맵·드롭 상세로 이어집니다. 타이머·조합 도우미는 게임 파티나 입장 상태를 자동 인식하지 않습니다.

## 도감과 이동

<a id="codex"></a>
### 통합 도감 · `/codex`

몬스터·아이템·맵·퀘스트·NPC·레시피·상점 종류를 고르고 이름·영문·ID·초성으로 검색합니다. 분류·최대 레벨을 조정하고 결과가 많으면 다음 페이지로 이동합니다. 항목을 눌러 상세 관계를 따라가며 별표로 즐겨찾기합니다. **내 레벨**은 현재 프로필을 사용하므로 프로필이 기본1레벨이면 검색도 달라집니다.

<a id="quests"></a>
### 퀘스트 도감 · `/quests`

이름·ID로 검색하고 **내 레벨·현재 직업**, **완료 숨기기**를 선택합니다. 체크박스로 실제 완료를 기록하면 추천의 선행 계산에도 반영됩니다. 현재 조건 밖 의뢰를 찾으려면 조건 필터를 해제하세요. 상세에서 선행·목표·보상·선택/랜덤 구분·원문 진행 단계를 확인하고 연결된 NPC·맵·아이템을 엽니다. 도감 조건에 뜬다는 사실만으로 숨은 스크립트 조건까지 충족한 것은 아닙니다.

<a id="items"></a>
### 아이템 도감 · `/items`

이름·ID·분류·최대 레벨로 찾고 상세에서 기본 옵션·착용 조건·드롭 몬스터·퀘스트·상점·제작을 확인합니다. 보유 재료는 해당 퀘스트 상세의 보유 수량 또는 묶음 계획의 준비 재료에 기록합니다. 기본 장비 수치와 판매 매물의 강화/추가 옵션은 다릅니다. 도감 이미지·클라이언트 항목만 존재하는 경우 실제 획득 가능성을 별도로 확인합니다.

<a id="monsters"></a>
### 몬스터 도감 · `/monsters`

이름·ID·레벨로 검색해 HP·EXP·출현 맵·드롭을 엽니다. 파티퀘스트/전직 시험 변형과 일반 몬스터를 구분하세요. 드롭 표본의 관찰 횟수·오차 범위·출처를 읽고, “드롭한다”와 “확률이 검증됐다”를 구분합니다. 맵·드롭 아이템을 누르면 해당 도감으로 이동합니다.

<a id="maps"></a>
### 월드맵 · `/maps`

월드맵의 핀을 눌러 해당 위치의 맵을 선택하거나 맵 목록에서 검색합니다. 맵 상세에서 미니맵·몬스터·NPC·포털 관계를 확인합니다. 이미지가 없거나 원본 API가 실패하면 이름·정보를 사용하고 이동 경로 도구에서 확인된 포털을 찾으세요. 스폰 수나 미니맵만으로 시간당 사냥 효율이 결정되지 않습니다.

<a id="npcs"></a>
### NPC · 상점 · `/npcs`

NPC 이름·ID로 검색해 위치와 판매 품목을 확인합니다. 아이템을 눌러 다른 획득처·레시피와 비교할 수 있습니다. 일반 단가·주민 가격·등급·재고를 구분하세요. 도감의 NPC 상점은 게임NPC 판매 정보이며 사용자들이 운영하는 **묶어팔기 상점**과 별도입니다.

<a id="route"></a>
### 이동 경로 · `/route`

출발 맵·도착 맵을 검색해 고릅니다. 현재 프로필 레벨을 맞추고 조건부 포털·교통 사용 여부를 선택합니다. 출발·도착 바꾸기로 역방향도 계산할 수 있지만 일방통행은 자동으로 역방향 사용되지 않습니다. 결과의 포털 순서와 조건을 읽고 맵 상세를 엽니다. “경로 없음”은 수집된 연결에서 못 찾았다는 뜻이며 모든 숨은 길의 부재를 뜻하지 않습니다. 최소 포털 수 경로이지 최저 이동 메소/시간 경로는 아닙니다.

## 편의도구와 측정

<a id="tools"></a>
### 모든 편의도구 · `/tools`

계산·기록·제작·코디·타이머·번역 도구의 바로가기 목록입니다. 카드를 눌러 실제 입력 화면으로 들어갑니다. 필요한 캐릭터 수치나 데이터는 각 도구에서 채워야 하며 목록을 연 것만으로 결과가 계산되지는 않습니다.

<a id="calculator"></a>
### 원컷 · 처치 계산 · `/calculator`

**먼저:** 실제 레벨·직업·스탯·무기 공격력/마력을 맞춥니다. 대상 몬스터를 검색해 선택하거나 HP·레벨·회피를 직접 입력합니다.

- **클래식 참조 공식**: 무기·공격 동작·주/보조 스탯·마스터리·스킬 계수·줄 수·명중·크리티컬·속성 반응·공격 주기를 입력합니다. 스킬 수치 채우기는 최대레벨 참조이며 현재 찍은 레벨과 같다고 가정하지 마세요.
- **실측**: 게임에서 본 최소/최대1줄 피해·공격 시도/적중 횟수를 넣습니다. 실제 피해가 이미 크리티컬을 포함한다면 중복 보정하지 않습니다.
- 처치 타수·원컷 확률·필요 명중을 읽습니다. 방어/속성/분포 가정이 미확인이면 계산값을 실제 서버의 확정 확률로 읽지 않습니다.

<a id="accuracy"></a>
### 명중 기록 · `/accuracy`

전투 계산과 같은 입력 구조를 명중 중심으로 사용합니다. 캐릭터·대상 레벨·대상 회피·직접 확인한 총 명중을 넣거나 참조 스탯 계산을 사용합니다. 실측 탭에서는 공격 시도·적중 횟수를 입력합니다. 예를 들어100회 중90회 적중은90%의 관찰값이지 다음100회의 적중률 보증이 아닙니다. 레벨 차이·실제 버프·장비가 달라졌다면 다시 측정하세요.

<a id="hunt"></a>
### 사냥 기록 · `/hunt`

**필수:** 현재 캐릭터의 실제 레벨·전직·스탯. 캐릭터를 잘못 선택하면 다른 사람의 실측으로 저장됩니다.

1. **측정할 사냥터**를 직접 적거나 이름/ID로 검색해 **도감 사냥터 선택**을 고릅니다. 도감 맵을 선택하면 추천 보정과 연결하기 쉽습니다.
2. **측정 조건 메모**에 무기·솔로/파티·버프·혼잡 등의 조건을 적습니다. **시작 레벨 안의 현재 경험치**에는 현재 레벨의 경험치 수치를 넣습니다.
3. **사냥 측정 시작**. 다른 화면으로 이동해도 시작 시각·입력을 보관합니다.
4. 종료 레벨·현재 경험치를 입력합니다. 경험치 표로 계산할 수 없는 경우 **획득 EXP 직접 확인 · 선택**에 실제 증가량을 넣습니다.
5. **획득 메소 · 지출 전**은 아이템 판매액을 제외한 획득액입니다. 물약·탄환·충전 비용, 이동·기타 비용을 따로 넣습니다. 이미 비용이 빠진 지갑 증감을 획득액으로 넣고 비용을 또 빼지 마세요.
6. **아이템·수량으로 기록**에서 전리품을 추가하고 수량·기록 가치를 확인합니다. 실제 전리품이 없었을 때만 **이번 사냥에는 전리품이 없었어요**를 체크합니다. 합계만 아는 경우 **전리품 가치 합계 직접 입력**을 사용할 수 있지만 추후 현재 시세 재평가가 제한됩니다.
7. **측정 마치고 저장**. 실제 레벨·경험치도 종료 입력으로 갱신됩니다. **측정 취소**는 결과를 저장하지 않습니다.

비용을 모르면 빈칸으로 남겨 EXP만 기록할 수 있습니다. 비용이 없음을 확인했다면0을 입력하세요. 아래 기록의 **아이템·조건 보완**에서 과거 합계를 전리품 목록으로 바꿀 수 있으며 합계와 아이템 가치를 이중 합산하지 않습니다. **지난 사냥을 합계로 직접 기록**은 실시간 측정 없이 과거 결과를 입력할 때 사용합니다. 사냥 추천은 현재 조건과 비교 가능한 측정 기록을 이용합니다.

<a id="exp"></a>
### 경험치 계산 · `/exp`

현재 레벨·목표 레벨·현재 레벨 경험치 비율을 입력합니다. 기록된 시간당EXP를 사용할 수 있으며 **시간당 EXP 직접 입력**으로 다른 속도를 비교할 수 있습니다.1–49레벨 표로 계산할 수 없는 구간은 **남은 경험치 직접 입력**을 사용합니다. 현재 레벨 입력은 실제 프로필도 바꾸므로 단순 가상 비교를 위해 실제 레벨을 덮어쓰지 않도록 주의하세요. 예상 시간은 같은 사냥 속도가 유지된다는 가정입니다.

<a id="crafting"></a>
### 제작 비용 · `/crafting`

레시피를 검색하고 제작 직업·시도 횟수·현재 제작 레벨을 입력합니다. 재료 보유량·NPC/현재 시장 단가·필요 조건을 확인한 뒤 누락 단가를 직접 지정합니다. 성공률·판매 수수료는 실제 조건을 확인해 가정값으로 넣습니다. 완제품 구매가/판매가를 지정하면 **이번 시도에 필요한 메소**, **보유 재료 가치까지 포함한 비용**, **완제품 구매 대비 차이**를 비교합니다. **제작 계획 저장**으로 현재 캐릭터 계획을 보관합니다. 숙련/캐릭터 레벨 제한, 주민 가격·재고·랜덤 옵션은 실제 게임 확인이 필요합니다.

<a id="scroll"></a>
### 주문서 시뮬레이터 · `/scroll`

성공 확률·잔여 업그레이드 횟수·목표 성공 횟수·실패 시 파괴 확률·주문서 가격을 입력합니다. 목표 이상 성공할 확률과 기대 성공 수를 비교하고 시뮬레이션 결과를 봅니다. 파괴가 발생하면 이후 시도가 중단됩니다. 결과는 입력한 독립 확률 가정의 계산이며 실제 강화 실행이나 결과 예측이 아닙니다. 실제 주문서 확률과 파괴 조건은 아이템 설명을 먼저 확인하세요.

<a id="dressing"></a>
### 코디룸 · `/dressing`

장비 부위를 고르고 이름으로 검색해 착용 미리보기에 추가합니다. 피부·헤어·얼굴·동작·확대·움직이는 미리보기를 조정할 수 있습니다. **코디 저장**으로 현재 캐릭터 외형을 저장하고 **코디 링크 복사**로 공유합니다. 받은 링크는 미리보기부터 확인합니다. 원본 렌더 실패 시 기본 코디로 돌아갈 수 있습니다. 여기서 보이는 장비는 게임 보유·출시·착용 가능·구매 상태를 증명하지 않습니다.

<a id="timer"></a>
### 버프 · 파티 타이머 · `/timer`

개인 타이머는 이름·지속 시간(초)을 넣어 추가하고 **시작/다시 시작**을 누릅니다. 알림 소리는 내 공간에서 켜고 브라우저 소리 권한도 확인합니다. 공유 타이머는 로그인 후 같은 모험 공간을 선택하고 이름·초를 입력해 **파티 타이머 시작**을 누릅니다. 참여자는 같은 공간에서 확인합니다. 화면을 닫았을 때의 푸시·게임 버프 자동 감지는 제공하지 않으며 기기 절전의 영향을 받을 수 있습니다.

<a id="order"></a>
### 전리품 순서 뽑기 · `/order`

파티원 이름을 한 줄에 한 명씩 입력하고 추첨합니다. 중복 이름은 제거되므로 동명이인은 구분 이름을 쓰세요.2명 이상 필요하며 결과를 복사해 게임 안에서 공유할 수 있습니다. 추첨은 실제 아이템 분배를 실행하지 않습니다.

<a id="chat"></a>
### 영어 채팅 도우미 · `/chat`

판매/구매/파티/도움 요청 상황을 고르고 영문 아이템·파티 이름, 가격, 수량·모집 인원, 만날 곳을 입력합니다. 생성 문장의 실제 거래 조건을 확인한 뒤 **문장 복사**로 게임에 직접 붙여 넣습니다. 템플릿이므로 임의 문장의 전문 번역이나 게임 채팅 자동 전송과 다릅니다.

<a id="liveTranslate"></a>
### 화면 읽기 · 번역 · `/liveTranslate`

파일/클립보드 이미지 또는 화면 공유 중 필요한 방식으로 게임의 영어 영역을 제공합니다. 화면 공유는 브라우저에서 직접 창/화면을 선택·허용해야 합니다. 읽은 영어 원문을 눈으로 대조하고 수정한 뒤 **기기 내 번역**을 사용합니다. 선택적으로 **5초마다 읽기**, **새 원문 자동 번역**, 지원 환경의 **게임 위에 띄우기**를 사용합니다. OCR 오인식·브라우저 번역 모델 설치/지원 차이가 있으며 실제 게임 전체 화면의 정확도를 보장하지 않습니다. 종료할 때 화면 공유도 중지하세요.

## 거래와 시세

<a id="market"></a>
### 시세 노트 · `/market`

**먼저:** 가격 종류·관찰 시각·아이템ID·단가/묶음 총액·옵션을 구분합니다. 내 게임 인벤토리를 자동 읽는 화면은 아닙니다.

| 탭 | 사용법 |
| --- | --- |
| Cozy 공개 시세 | 아이템 검색 → 선택 → 매도/매수·관찰 종류·정렬·관찰 매물 연령 선택. 최근 시각·판매자·채널·위치·옵션을 확인하고 필요하면 기록 보관 |
| 글클메지지 시세 | 연결 상태 확인 후 아이템을 선택하면 호가 통계·옵션·일별 이력·가격 글을 표시. 현재 서버 요청403이면 미연결로 표시하며 새 가격이 있다고 간주하지 않음 |
| 시세 기록 | 수동 기록과 허용된 현재 공급원 자료를 검색. 가격 종류·최대 단가·확인 범위로 필터. **+ 가격 기록**으로 직접 확인한 아이템ID·단가·수량·시각·출처 입력 |
| 매물 탐색 | 같은 아이템과 실제 옵션을 기준으로 판매자·채널·위치·연락 메모를 확인. 가격 정렬 전에 단가/최소 구매 총액을 구분 |
| 가격 비교 | 동일 옵션·관찰 범위에서 낮은 호가 후보 비교. 다른 강화·공격력·업횟수 장비를 같은 상품으로 보지 않음 |
| 관심 검색 | 관심 검색 이름·아이템 검색어/정확한ID·목표 최대 단가·최신성·필요 옵션을 저장. 탭이 열린 동안 조건에 맞는 관찰을 확인 |
| 가격 이력 | 아이템과 기간을 선택해 실제 보관된 관찰 가격의 변화를 확인. 새 조회와 새 거래 관찰은 별개 |
| 내 화면 가격 | 사용자가 제공한 화면에서 OCR 가격 후보를 읽고 아이템·숫자·단위·옵션을 직접 확인한 뒤 저장. 검토 전에는 실제 가격으로 확정하지 않음 |
| 연결·갱신 | 공급원·마지막 조회·실제 관찰·자동 확인 간격·이력 저장소 상태 확인. 네트워크 오류/403/오래된 관찰을 구분 |

호가는 판매자의 희망 가격이며 **판매 보고·관찰**도 전체 서버의 확정 체결 원장이 아닙니다. 시세는 보통60초 단위로 조회하지만 새 거래가 없으면 실제 관찰 시각은 그대로입니다. 화면을 닫은 뒤의 예약 수집은 별도 설정이며 현재 비활성 상태입니다.

새 가격을 돈퀘·사냥·장비 추천에 반영하려면 추천 화면에서 **추천 새로 계산**을 누릅니다. 관심 검색에 걸린 매물이 실제로 남아 있는지 게임에서 확인하고, 거래 제한 해제 전에는 구매 가능한 것으로 계획하지 않습니다.

<a id="owl"></a>
### 미네르바의 부엉이 · `/owl`

시세/매물 자료에서 아이템·옵션을 좁혀 단가·최소 구매비·판매자·채널·위치를 비교합니다. 해당 호가의 관찰 시각과 실제 판매 상태를 확인하세요. 이 앱에 연결/등록된 관찰 범위의 탐색이며 글클메지지 로그인 후 부엉이 결과나 서버 전체 상점을 그대로 가져온 것은 아닙니다.

<a id="trade"></a>
### 아이템 거래소 · `/trade`

**먼저:** 모험 공간을 선택합니다. **+ 글 작성**에서 삽니다/팝니다, 제목·설명·아이템ID·개당 가격·수량·채널·장소·게임 연락처·옵션을 입력합니다. 저장 후 검색·가격 정렬·관심 표시를 사용할 수 있습니다. 자기 글만 수정/완료 처리하고 거래가 끝나면 닫으세요. 이 사이트의 게시물이며 다른 서비스의 회원·기존 거래 글이 자동으로 복제되지는 않습니다.

<a id="shop"></a>
### 묶어팔기 상점 · `/shop`

같은 모험 공간에서 **상점 열기**를 누르고 상점 제목·설명·연락처와 개별 상품명·개당 메소·재고를 추가합니다. 상품/재고를 확인해 저장합니다. 구매자는 개별 수량을 골라 장바구니 합계와 남은 재고를 비교하고 판매자에게 문의합니다. 앱의 장바구니는 게임 내 결제·재고 예약·아이템 지급을 실행하지 않습니다. 판매자는 실제 재고가 바뀌면 수정/완료 처리해야 합니다.

<a id="megaphone"></a>
### 확성기 노트 · `/megaphone`

직접 복사한 고확 원문을 가져온 뒤 검색어·거래 종류·가격 후보로 찾아봅니다. 같은 원문의 중복을 줄이고 거래 문장에서 추출한 숫자를 검토합니다. `k`/`m`·개당/묶음·아이템 이름을 반드시 대조하세요. 게임 서버 전체 확성기의 자동 수집 스트림이 아니며 원문을 넣지 않으면 기록도 생기지 않습니다.

## 친구와 함께 쓰기

### 모험 공간과 접근 권한

거래/파티/쪽지/공유 타이머의 **모험 공간**에서 **공간 만들기**로 만들고 초대 코드를 친구에게 전달합니다. 친구는 **초대 코드로 참여**한 뒤 같은 공간을 선택합니다. **나의 기록 · 개인**은 개인 공간이며 같은 문자열을 입력했다고 공유 구성원이 되지 않습니다. **이 사이트의 모험가 · 공동**은 사이트 이용자 대상 공동 범위입니다.

사이트 자체는 현재 소유자 전용입니다. 친구가 사이트를 열 수 있는 접근 권한과 앱 안의 모험 공간 참여는 별도이므로, 초대 코드만으로 사이트 접근이 허용되지는 않습니다. 이 문서는 접근 범위를 변경하지 않습니다. 캐릭터 프로필을3개 만들어 둔 것과3명이 같은 계정으로 로그인한 것도 서로 다릅니다.

<a id="party"></a>
### 파티 구인·구직 · `/party`

같은 공간을 선택하고 **파티 모집**에서 목적·제목·조건·정원·채널·장소·연락처를 적습니다. 참여자는 신청 메모에 직업·레벨·연락 방법을 적습니다. 모집자는 신청을 수락/거절하고 정원이 차거나 종료하면 글을 닫습니다. 같은 파티의 중복 신청/중복 수락과 동시 정원 초과를 서버에서 검사합니다. 게임 안 파티 초대·탈퇴는 직접 해야 합니다.

<a id="messages"></a>
### 우리 쪽지 · `/messages`

로그인 후 같은 공간의 구성원을 받는 사람으로 선택해 제목·내용을 씁니다. 받은함/보낸함에서 상세·읽음·답장을 확인합니다. 나에게 메모도 가능합니다. 앱 내부 쪽지이며 Discord·이메일·게임 귓속말로 전송하지 않습니다. 공간 참여와 받는 사람을 확인하고 민감한 계정 정보는 적지 마세요.

<a id="nickname"></a>
### 닉네임 게시판 · `/nickname`

모험 공간에서 글 작성으로 닉네임 관련 제목·조건·설명·게임 연락 메모를 남깁니다. 검색·관심·자기 글 수정/종료를 사용할 수 있습니다. 실제 닉네임 소유·변경 가능·이전 완료를 확인하거나 게임 계정을 조작하는 기능은 아닙니다.

## 수치 해석과 확인 범위

- **공용 보상 가치**: 해당 의뢰 자체의 확정 메소와 가격이 확인된 확정 보상 아이템의 가치. 비용 차감 전이며 직업 성능·보유 재료·미완료 선행 보상을 더하지 않습니다.
- **확인된 일부 보상**: 전체 보상/가격이 미확인인 경우 현재 합산할 수 있는 부분. 전체 가치나 순이익으로 단정하지 않습니다.
- **준비 구매비**: 가진 재료를 제외하고 실제 추가 준비에 필요한 구매비·진행 비용. 묶음 최소 구매비가 포함될 수 있습니다.
- **순가치**: 보상에서 소모 재료 가치와 진행 비용을 뺀 경제적 가치. 이미 가진 재료도 판매 기회비용이 있습니다.
- **기록 당시 가치 / 현재 추정 가치**: 기록 때의 가격과 현재 관찰 가격을 분리합니다. 전리품을 아직 팔지 않았다면 지갑 수익과 다릅니다.
- **확인 필요**: 빈 값·근거 부족이지0이라는 뜻이 아닙니다. 원문 확인이나 실제 게임 관찰이 필요한 경우입니다.

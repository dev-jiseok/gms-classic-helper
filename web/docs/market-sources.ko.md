# 시세와 공식 자료 연동

2026-10-21 확인 기준입니다. 글클메지지의 전체 기능을 기본으로 재현하는 과정에서 가격의 출처·종류·옵션·확인 시각도 보존합니다.

## 현재 동작

- 시세·매물: 사이트가 열린 동안 기본 60초마다 우리 공간 게시물을 읽습니다. 1·2·5분 설정, 요청 중복 방지, 연결 실패 시 지수형 재시도, 직접 확인 버튼을 제공합니다. 브라우저 절전·백그라운드 제한으로 정확한 초 단위 실행을 보장하지 않습니다.
- 외부 가격: `/api/market`은 기본으로 Cozy Market 자체 화면 관찰 피드를 연결합니다. 실제 확인 결과 1,127개 아이템 집계와 903개 마지막 판매 관찰 가격을 받았습니다. 공급원 응답 시점 2026-10-21 05:41 UTC 기준 최근 판매 표본은 05:40:41 UTC였습니다. 앱 기본 확인과 서버 공급원 캐시는 60초입니다. 공개 응답의 Cache-Control은 15초이고 별도 최소 간격은 발견하지 못했으며, 429·Retry-After는 준수합니다. 1·2·5분 앱 확인 설정을 제공합니다.
- 내 화면 가격: 사용자가 고른 게임 화면을 기기 안에서 OCR로 읽습니다. 5초 자동 읽기는 `ScreenReader`의 사용자 선택 기능이며, 인식 결과는 검토 대기 후보로만 둡니다. WTS·WTB·k·m·메소와 장비 옵션을 추출하고 여러 가격·묶음·낮은 신뢰도를 표시합니다. 개당 가격 확인과 원문 대조 체크를 모두 마친 기록만 추천에 반영합니다. 이미지 파일은 서버에 업로드하지 않으며, 검토해서 저장한 가격의 원문·신뢰도·최초 관찰 시각은 프로필 저장에 포함합니다. 실제 게임 화면의 인식 정확성은 별도 실사용 검증이 필요합니다.
- 직접 기록·CSV·JSON: 가격 종류, 실제 확인 시각, 수량, 장비 옵션을 검증하고 가져옵니다. 확인 시각이 없는 가져오기는 현재 시각으로 바꾸지 않고 오류를 표시합니다.
- 비교: 개당 가격으로 환산하며 묶음은 최소 구매 수량·총액을 보존합니다. 장비는 옵션 전체가 확인된 같은 조건끼리 비교하며, 옵션 미확인 장비를 서로 같은 장비로 묶지 않습니다. 가격 기록이 하나뿐이면 가상의 할인율을 만들지 않습니다.
- 관심 조건: 목표 단가·아이템·옵션·기록 연령을 저장합니다. 아이템 ID가 있는 조건의 고유 아이템을 한 번에 6개씩 순환하며, 아이템당 최근 30행을 확인합니다. 전체 항목 수·예상 한 바퀴 시간·항목별 마지막 조회 시각·실패를 표시합니다. ID 없는 검색어 조건은 이미 모인 기록에서만 찾습니다. 같은 조건·매물·가격에 대한 알림은 한 번만 만들고, 가격이 바뀌면 다시 확인합니다. 앱 안 알림과 사용자가 허용한 브라우저 알림을 지원합니다. 사이트를 닫으면 갱신·알림이 중지됩니다.

매수·매도 호가, 판매 보고·관찰을 구분합니다. Cozy의 판매는 회색·매진 행을 판매로 추정한 화면 관찰이며 확정 체결 원장은 아닙니다. 관찰된 최저 호가를 전체 서버 최저가로 표시하지 않습니다. 혼합 아이템 묶음 상점의 전체 가격을 단일 아이템 단가로 잘못 편입하지 않습니다.

## 허용된 외부 JSON 공급원 설정

기본 Cozy 대신 별도 허용 공급원을 연결하려면 운영 환경의 서버 변수만 사용합니다. 브라우저에서 임의 주소를 받아 프록시하지 않고, 토큰을 브라우저에 보내지 않습니다.

| 서버 변수 | 의미 |
| --- | --- |
| `MARKET_FEED_URL` | 고정된 HTTPS JSON 주소 |
| `MARKET_FEED_ALLOWED_HOSTS` | 해당 주소의 정확한 호스트 이름 목록, 쉼표 구분 |
| `MARKET_FEED_REUSE_ALLOWED` | 공급원이 자동 수집·이용을 허용한 경우에만 `true` |
| `MARKET_FEED_NAME` | 화면에 표시할 출처 이름 |
| `MARKET_FEED_TOKEN` | 필요한 경우 서버 전용 Bearer 토큰 |
| `MARKET_FEED_MIN_INTERVAL_SECONDS` | 공급원이 허용한 최소 확인 간격, 기본 60초·최소 30초 |

공급원은 `{ "quotes": [...], "updatedAt": "ISO 시각" }`를 반환합니다. 각 기록에는 `id`, `itemId` 또는 `itemName`, `type`(`buy`/`sell`/`sold`), 양수 `price`, 정수 `quantity`, 실제 관찰 시각 `at`가 필요합니다. `options`에 공격력·마력·스탯·명중·잔여 업횟수를 넣고, 모두 확인되었을 때만 `optionsComplete: true`로 둡니다. `priceBasis` 기본값은 개당 `unit`이며 동일 아이템 묶음 가격일 때만 `bundle`로 명시합니다.

브라우저에는 공급원의 현재 기록 전체를 실행 상태로 표시합니다. 자동 공급원 가격과 우리 공간 매물을 계정 가격 배열에 매분 복제하지 않습니다. 추천 화면은 `useMarketPrices()`로 직접 보관한 가격과 현재 공급원 기록 전체를 사용합니다.

공급원 요청은 서버에서 60초 캐시·ETag·동시 요청 합치기를 적용합니다. 리다이렉트는 따라가지 않고 사설 주소·인증 포함 주소·허용 목록 밖 호스트를 거절합니다. 429의 `Retry-After`와 지수형 재시도를 따르며, 실패해도 마지막 정상 기록의 실제 시각을 보존합니다. 캐시는 Worker 실행 단위이므로 별도 공급 계약의 전역 요청 한도가 엄격하면 중앙 캐시·수집기를 공급원 앞에 두어야 합니다.

## 랭킹과 공식 소식

- [ClassicRank 개발자 문서](https://classicrank.com/developer): 키 없는 읽기 API를 명시적으로 제공합니다. `/api/v1/characters`, `/jobs`, `/stats`의 실제 HTTP 200 응답을 확인했습니다. 공개 한도는 IP당 분당 30요청, 페이지당 최대 50명, 첫 1,000개 결과입니다. 우리 서버는 최소 30초 캐시와 동시 요청 합치기·제한 대기를 사용합니다. 실제 스캔 시각과 API 조회 시각을 분리합니다.
- [Steam ISteamNews 공식 문서](https://partner.steamgames.com/doc/webapi/ISteamNews): 키 없는 `GetNewsForApp/v2`를 통해 Nexon이 게시한 `steam_community_announcements` 피드를 읽습니다. MapleStory와 Classic World가 앱 ID 216150을 공유하므로, Classic 전용 제목·점검 대상·배너·초기 문단을 확인한 공지만 반환합니다. 일반 MapleStory 이벤트와 Classic를 한 번 언급한 일반 행사 안내는 제외합니다.
- 뉴스에는 제목·종류·게시 시각·공식 원문 링크를 표시합니다. 게시 시각을 이벤트 기간으로 사용하지 않습니다. 사용자 일정으로 저장할 때는 원문의 실제 시작·종료 시각을 직접 확인해야 합니다. 뉴스는 15분 캐시·연결 실패 재시도·마지막 확인 시각을 제공합니다.

# GMS Classic Helper

GMS Classic World 도감·공략·거래·사냥·캐릭터 계획을 연결하는 개인 도우미입니다. 기본 세 프로필은 파이터·표도·궁수의 Lv.1 출발이며, 초보자·1차 네 계열·2차 열 직업 모두 선택·추가할 수 있습니다.

**현재 버전은0.6.1입니다.** 전체 구현 현황·데이터 규모·남은 범위는 [프로젝트 README](../README.md)에 정리되어 있습니다. 실제 사용자를 위한 [42개 기능 사용 설명서](docs/README.md)에 프로필 설정, 돈퀘 공용 보상 가치 정렬, 각 화면의 입력 순서와 결과 해석을 정리했습니다. 이 문서는 앱 실행·저장·데이터 운영을 설명합니다.

0.4.0부터 글클메지지의 공개 구조를 기준으로 가로6개 메뉴·마을 배경·이미지 카드·게임 패널·시세표/상세2단·모바일 하단탭을 재구성했습니다. 실제 게임 이미지와 기존 개인 추천 기능을 연결합니다. [화면 재현 범위·이미지 출처](docs/visual-reconstruction.ko.md)를 참고하세요.

공략의 출처·SP 규칙·확인 범위는 [정확성 검토](../research/guide-accuracy-review-2026-10-21.ko.md)에 정리했습니다. 출처 대조와 실제 게임 효율 검증을 구분합니다.

## 실행과 검증

Node.js 22.13 이상을 사용합니다.

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 5187
npm run check
npm test
npm run build
```

개발 서버는 `http://127.0.0.1:5187`입니다. 외부 API를 확인할 때는 실행 환경의 네트워크 접근이 필요합니다. 로컬의 `/signin-with-chatgpt?return_to=/`는 고정 개발 계정 로그인입니다. 호스팅에서는 Sites가 실제 ChatGPT 인증을 담당합니다.

빌드된 Worker는 `npm start -- --port 5188`로 실행합니다. 루트의 `scripts/qa-social-live.mjs`는 **로컬 빌드에만** 임시 계정 헤더를 넣어 계정 간 권한·동시성을 확인하며 외부 주소 실행을 거부합니다. 실제 배포의 인증 헤더는 Sites가 부여합니다.

D1 마이그레이션은 `drizzle/`의 SQL을 번호순으로 한 번씩 적용합니다. Sites 배포는 마이그레이션을 포함합니다. 로컬 적용 예:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_faulty_layla_miller.sql
```

이미 적용한 SQL은 다시 실행하지 않습니다.

| 우리 거래 공간 | 로그인 계정과 공유 공간 D1 | 공간 게시물 30초, 가격 소비 60초 기본 |
| 내 게임 화면 가격 | 사용자가 선택한 화면·이미지의 영어 OCR | 5초 OCR 선택 가능. 단가·원문 확인 뒤 가격 기록 반영 |

Cozy 참여자가 관찰한 범위의 시세입니다. 게임 전체의 매물·최저가·실제 체결을 보장하지 않습니다. 옵션이 확인되지 않은 장비 집계 가격을 최적 장비 매물로 사용하지 않습니다. 공급원 설정과 실제 확인한 제한은 [시세 연동 설명](docs/market-sources.ko.md)에 있습니다.

## 기능

- 전체 공개 색인 검색, 한글·영문·초성·ID 검색, 아이템↔몬스터↔맵↔퀘스트↔NPC 상점↔제작 연결
- 퀘스트315개 상세 보강·원문 진행 단계837개·실제 전직/시민권 조건·보유/소비 재료 구분·다중 의뢰 공통 선행·준비표·NPC/맵 동선·완료 기록
- 전 직업 가이드·무기별 스킬 분기·투자 우선순위·레벨별 SP 미리보기·최대치·선행·SP 이월·공유
- 현재 클래식 커뮤니티 공식의 데미지·명중·원컷 확률, 실측 범위 비교, 미확인 방어 감소 명시
- 사냥 측정·아이템별 전리품·기록 당시/현재 가치 비교·합계 기록 보완·조건이 같은 캐릭터 기록 비교
- EXP/순메소 목표별 사냥 비교, 퀘스트 선행 묶음, 예산·부위·착용 조건·명중·잠금·최저 동등 옵션의 장비 조합
- 시세·매물 종류 구분, 단가/최소총액 정렬·옵션 검색·60초 상세 갱신·관심 목록 순환·실제7/30일 이력
- 공유 공간·초대 코드·거래소·개별 재고 상점·장바구니 문의·파티 신청/수락·쪽지·읽음·공유 타이머
- 실제 맵 방향·포털·레벨·퀘스트/아이템 조건을 반영한 경로
- 실제 게임 장비·얼굴·머리·스킨·동작 렌더 코디와 공유 링크
- 전체 제작 레시피·NPC 조건·시민권 할인·재료 기회비용·현금 필요액·구매/제작 비교
- 시민권 진행·회전 게시판 선택·상점 등급, 파티퀘스트 쿠폰·조합·진행 타이머
- 공식 출시 공지의 이벤트8개·실제 기간·보상·조건, 초반 우선 행동·거래 해제·주택 준비 공략
- 주문서 확률·파괴 실험, 영어 채팅, 화면 OCR·지원 브라우저 번역·미니창, 이벤트 일정·백업

일반 착용 장비1,203개의 메타를 확보했고 기본 착용 조건1,202개를 확인했습니다. 명성·특수 조건은 출처가 없으면 미확인으로 유지하며 실제 매물 옵션은 별도 검토합니다.

[전체 기능 대조표](docs/feature-coverage.ko.md)는 구현과 외부 의존·실사용 확인 범위를 구분합니다. [서버 시세 수집](docs/market-collection.ko.md)은 개인 프로필을 건드리지 않는 공유 자료 수집·재조회 경로를 설명합니다.

## 자료 정확성과 이용 조건

공개 MCW 클라이언트 색인에 있는 항목이 모두 현재 게임에서 출시되거나 획득 가능하다는 뜻은 아닙니다. 각 항목의 버전·확인일·출처·확인 수준을 표시합니다. Wiki 자료는 커뮤니티 참조이며 실제 게임·공식 패치를 우선합니다.

확률을 알 수 없는 드롭을 기대 수익에 임의로 합산하지 않습니다. 플레이어 드롭 제보는 표본·오차 범위와 함께 별도 표시합니다. 랜덤·선택 보상을 전부 확정 보상으로 더하지 않습니다. 호가와 보고된 체결은 구분하며, 관찰 범위 최저가를 게임 전체 최저가로 표현하지 않습니다.

MapleClassic Wiki 공개 구조화 자료·공식·참조는 **CC BY-NC-SA 4.0** 조건으로 정규화·한국어 표기를 추가한 자료입니다. 원문 링크와 확인일을 유지합니다. 게임 아이콘·렌더링 리소스의 권리는 NEXON에 있으며 maplestory.io에서 제공합니다. 앱의 SVG 캐릭터와 CSS 배경은 직접 작성했으며, 홈 배경은 자체 생성한 이미지입니다. [이미지 출처와 재현 범위](docs/visual-reconstruction.ko.md)를 참고하세요.

`node scripts/refresh-public-catalog.mjs`는 공개 공급원을 다시 조회하고 도감·직업·EXP 스냅샷을 재생성합니다. 문서에 기록된 검증을 통과한 뒤 새 버전으로 배포합니다. 비공개 시세 사이트 수집기는 포함하지 않습니다.

## 저장과 공유

브라우저 저장 + 로그인 계정별 D1 저장을 사용합니다. 같은 계정의 동시 편집은 revision 충돌을 차단하고 현재 기기 백업·계정 최신 기록 선택을 제공합니다. JSON 백업 복원 한도는 2MB입니다.

개인 기록은 다른 계정에 노출하지 않습니다. 공유 공간은 가입한 계정만, 쪽지는 발신자·수신자만 읽을 수 있습니다. 초대 코드는 앱 안 공간 참여용이며 사이트 자체 접근 허가는 Sites 공유 설정과 별개입니다. 배포 사이트의 기존 비공개 접근 범위를 유지합니다.
